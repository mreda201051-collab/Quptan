QUPTAN WE EGYPT PRO — ملف المشروع
================================

المحتويات
- مشروع Flutter Android يفتح واجهة التطبيق المرفقة داخل WebView.
- إدارة المبيعات والعملاء والحجوزات والتحصيلات والتقارير.
- حسابات محلية متعددة على نفس الهاتف: لكل مستخدم اسم دخول وكلمة مرور وبيانات منفصلة.
- إنشاء كل حساب يبدأ بقاعدة بيانات جديدة وفارغة من العملاء والمبيعات.
- لا يتم استيراد بيانات العملاء القديمة تلقائيًا.
- لا يوجد Google Drive أو نسخ سحابي أو Excel في هذا الإصدار.
- لا يوجد نظام اشتراكات أو أكواد تفعيل.
- يمكن تغيير يوم بداية دورة الحساب من الإعدادات.

ملاحظات مهمة
- الحسابات محلية على نفس الهاتف وليست حسابات إنترنت، ولا تنتقل تلقائيًا إلى هاتف آخر.
- كلمة المرور محفوظة كبصمة SHA-256، لكن بيانات التطبيق المحلية ليست مشفرة بالكامل؛ لا تعتبرها حماية بمستوى خزنة آمنة.
- تسجيل الخروج يمنع فتح الواجهة دون كلمة المرور، لكنه لا يمحو بيانات الحساب من الهاتف.
- PIN والبصمة غير منفذين في هذه الحزمة.
- لم يتم اختبار APK على جهاز فعلي ضمن إعداد هذه الحزمة. يجب بناء APK من GitHub Actions ثم اختباره قبل الاستخدام الفعلي.

البناء من الهاتف عبر GitHub
1) ارفع محتويات المجلد إلى جذر مستودع GitHub، وليس ملف ZIP وحده.
2) تأكد من ظهور assets وlib و.github وpubspec.yaml مباشرة في جذر المستودع.
3) افتح Actions وشغّل Build QUPTAN PRO APK.
4) بعد نجاح التشغيل افتح Artifacts وحمّل QUPTAN-PRO-release-apk.
